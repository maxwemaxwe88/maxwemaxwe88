# OI Screener - Криптовалютный скринер открытого интереса

Скринер для отслеживания изменений открытого интереса (OI) на фьючерсных рынках криптовалют. Поддерживает множество бирж и отображает данные в режиме реального времени.

## Возможности

- **Множество бирж**: Binance, Bybit, OKX, Bitget, Gate.io, MEXC, KuCoin, HTX
- **Реальное время**: Данные обновляются каждые 10 секунд через WebSocket
- **Многопанельный интерфейс**: Каждая биржа в отдельном окне, как на Coinglass
- **Сортировка**: По изменению OI (5м, 1ч, 24ч), цене, объёму
- **Фильтрация**: По минимальному OI и поиск по символу
- **Подсветка изменений**: Обновлённые данные подсвечиваются

## Установка

```bash
# Установите зависимости
pip install -r requirements.txt

# Запустите приложение
python run.py
```

## Использование

1. Откройте в браузере: http://localhost:8000
2. Выберите биржу или смотрите все сразу
3. Настройте сортировку (по умолчанию: OI 5м% по убыванию)
4. Установите минимальный OI для фильтрации мелких монет
5. Используйте поиск для быстрого поиска нужного символа

## Технологии

- **Backend**: FastAPI, Python 3.10+
- **Frontend**: Vanilla JS, CSS Grid
- **Данные**: REST API бирж, WebSocket для обновлений

## API Endpoints

- `GET /` - Главная страница
- `GET /api/exchanges` - Список бирж
- `GET /api/oi` - Данные OI со всех бирж
- `GET /api/oi/{exchange}` - Данные OI с конкретной биржи
- `WS /ws` - WebSocket для real-time обновлений
